教材下载器 国家中小学智慧教育平台

把智慧教育平台的电子教材和课程资源存成本地 PDF，支持一次下一整套。免费公共资源，下的是你账号本来就能看的内容。

1

登录智慧教育平台

下载要用到你账号的访问令牌。已经登录过就直接看第 2 步。

打开智慧教育平台 直接去登录页
2

装一次下载器

平台服务器只允许自家域名跨域取文件，所以下载动作必须跑在平台页面上。 把下面的按钮拖到浏览器书签栏就装好了，只需一次。

📥 教材下载器

↑ 按住它，拖到上方书签栏

看不到书签栏？按 Ctrl+Shift+B 打开。
拖不动 / 点了没反应？用控制台方式（一定能成）

在智慧教育平台页面上按 F12 → 切到 Console → 粘贴代码 → 回车。 首次可能需要按提示手动输入 allow pasting 再回车解锁粘贴。

✓ 已复制
3

下载

  1. 在智慧教育平台的任意页面点书签栏里的「📥 教材下载器」。
  2. 右下角弹出下载面板，当前页面的网址已自动填好。
  3. 想下别的就把网址粘进去，一行一个可批量下载。
  4. 点「开始下载」，PDF 存进浏览器默认下载文件夹。

两类网址都认：

教材（整本电子课本，一个 PDF）
https://basic.smartedu.cn/tchMaterial/detail?…&contentId=708256b6-…

课程（同步课堂，自动把课件、教学设计、学习任务单、课后练习一次全下）
https://basic.smartedu.cn/syncClassroom/classActivity?activityId=b1a405c2-…
课件下到的是平台转好的 PDF —— 平台不提供原始 pptx。视频课程是 m3u8 流，不支持。

下载报 401/403 → 登录过期了，回平台刷新一下页面再试。
